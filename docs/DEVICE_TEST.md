# 魅族真机验收清单

自动测试验证通知更新及清理逻辑；以下项目需要真实 Flyme 系统验证，目前不宣称已通过。

记录：手机型号 / Flyme 版本 / Android 版本 / YT Music 版本 / 补丁版本。

- 从 GitHub 来源导入；确认名称为 Flyme Lyrics Patches (community)，可选 Flyme status bar lyrics。
- 对原版 APK 同时应用该补丁、Third-party lyrics 和必要的 GmsCore/后台播放补丁，安装后正常登录播放。
- 播放有同步歌词的歌曲；对比锁屏歌词与状态栏文本，包括翻译、长句、中文、日文和换行。
- 同一句歌词期间暂停：状态栏歌词消失，媒体通知与播放按钮仍保留；恢复后歌词重新出现。
- 快速切换歌曲、拖动进度、播放间奏和无歌词歌曲：不得残留上一首歌词。
- 分别关闭魅族歌词、锁屏歌词和第三方歌词开关：状态栏清空；重新开启后恢复。
- 后台播放、熄屏、锁屏后解锁、原应用重新发布媒体通知：应持续更新。
- 停止播放、退出/强制停止、移除播放会话：不留常驻歌词，不新增通知。
- 点击上一首/下一首/暂停、查看封面：原有媒体通知功能不变，无每句提示音或震动。
- 在不支持 Flyme 专用标志的设备上：不崩溃，不更改通知，官方歌词仍正常。

排查顺序：先确认官方锁屏歌词有效，再检查三个开关和 Flyme 的应用通知/状态栏歌词设置。若日志出现 `Flyme status bar lyrics unavailable`，提供相关错误信息。固件如果限制反射或通知更新，补丁会安全跳过而非绕过系统策略。
