# 魅族真机复测

此前版本：用户已确认状态栏歌词真机可用，手动添加 JSON 成功。以下是 2.2.0 新增行为的复测步骤。

1. 从 README 来源链接进入 Morphe，确认范围是 YouTube Music。刷新后检查版本为 2.2.0、补丁数为 1，再打开应用的补丁列表。手动 JSON 来源应得到相同结果。
2. 从原版 APK 同时选中官方 Third-party lyrics 与 Flyme status bar lyrics，安装并开启第三方歌词总开关。
3. 新安装时，魅族状态栏歌词应默认打开。关闭迷你播放器歌词，播放有同步歌词的歌曲，检查状态栏仍逐句显示，而迷你播放器只显示歌名。
4. 开启迷你播放器歌词，两处应显示同一行（含翻译和歌名回退）；关闭魅族开关，只有状态栏清除。两个开关同时关闭时两处均不显示歌词。
5. 将状态栏偏移从默认 −800 ms 改为 0、+500 ms；比较同一句歌词的切换时刻，迷你播放器和锁屏不应随之改变。选择「跟随官方」后，再调整官方偏移并比较。
6. 重启后检查魅族开关仍保留。恢复开启后验证暂停、切歌、无同步歌词、关闭第三方歌词总开关和后台播放，确认通知封面与按钮正常。
